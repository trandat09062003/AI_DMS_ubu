1. TỔNG QUAN DỰ ÁN
--------------------------------------------------------------------------------
Hệ thống Giám sát Tài xế AI (AI_DMS) là giải pháp IoT nhúng kết hợp Trí tuệ Nhân tạo
chuyên sâu nhằm phát hiện sớm các trạng thái nguy hiểm của tài xế khi điều khiển phương tiện:
- Buồn ngủ nhẹ (Nhắm mắt liên tục >= 1.5 giây).
- Ngủ gật nguy hiểm / Vi giấc ngủ (Microsleep nhắm mắt >= 3.0 giây).
- Ngáp liên tục (MAR vượt ngưỡng).
- Mất tập trung / Nghiêng đầu / Ngoảnh mặt khỏi hướng lái (Head Pose Pitch/Yaw/Roll).

Hệ thống hoạt động theo cơ chế Headless (không bắt buộc có màn hình HDMI lớn trên xe),
tự động quản lý mạng, phát âm thanh giọng nói Tiếng Việt, hiển thị màn hình phụ OLED,
ghi âm cabin, gửi cảnh báo tức thì qua Telegram và cung cấp Web Dashboard quản trị
tại địa chỉ cố định: http://wifi.local.

2. DANH SÁCH CÁC MODULE VÀ TỆP TIN CHÍNH
--------------------------------------------------------------------------------
- drowsiness_detector.py : Module trung tâm AI, xử lý camera, MediaPipe Face Mesh,
                           tính toán EAR/MAR, suy luận mô hình LSTM, điều khiển logic cảnh báo.
- lstm_model.py          : Định nghĩa kiến trúc mạng PyTorch LSTM dự đoán chuỗi hành vi.
- lstm_drowsiness.pth    : Trọng số mô hình LSTM đã được huấn luyện sẵn.
- train_lstm.py          : Kịch bản thu thập dữ liệu và huấn luyện lại mô hình LSTM.
- audio_manager.py       : Quản lý ngõ ra âm thanh Jack 3.5mm, mạch TDA2050, phát còi bíp,
                           phát giọng nói Tiếng Việt và ghi âm cabin qua micro USB Camera.
- audio_prompts/         : Thư mục chứa các tệp âm thanh mẫu (còi bíp, giọng nói cảnh báo).
- oled_manager.py        : Driver I2C SSD1306 điều khiển màn hình OLED 0.96 inch 128x64.
- telegram_bot.py        : Xử lý gửi tin nhắn, ảnh chụp vi phạm và file ghi âm qua Telegram.
- wifi_dashboard.py      : Web Dashboard quản lý hành trình, cấu hình mạng Wi-Fi, cài đặt
                           Telegram và kiểm tra phần cứng (Cổng 80).
- mdns_publisher.py      : Dịch vụ công bố tên miền cố định http://wifi.local và http://dms.local.
- setup_autohotspot.sh   : Script cấu hình tự động phát trạm Wi-Fi Hotspot khi không có mạng.
- run_dms.sh             : Script khởi chạy toàn bộ các dịch vụ hệ thống với 1 lệnh duy nhất.
- view_history.py        : Công cụ dòng lệnh (CLI) truy vấn và xuất CSDL SQLite ra file CSV.
- test_hardware.py       : Công cụ kiểm tra toàn diện phần cứng (Màn hình, OLED, Loa, GPIO).
- test_oled.py           : Kiểm tra độc lập màn hình OLED I2C 128x64.
- test_speaker.py        : Kiểm tra độc lập ngõ ra âm thanh Jack 3.5mm và giọng nói Tiếng Việt.
- test_camera.py         : Kiểm tra độ phân giải, định dạng MJPG và FPS của Camera USB.
- camera_config.json     : File lưu cấu hình tham số Camera (USB/CSI, độ phân giải, FPS).
- calibration_config.json: File lưu ngưỡng hiệu chuẩn mắt/miệng của từng tài xế.
- telegram_config.json.example : File mẫu cấu hình kết nối Telegram Bot.
- requirements.txt       : Danh sách các thư viện Python phụ thuộc.

3. SƠ ĐỒ CHÂN KẾT NỐI PHẦN CỨNG (RASPBERRY PI GPIO)
--------------------------------------------------------------------------------
+-------------------+---------------+------------------+---------------------+
| Thiết bị / Module | Chân Module   | Chân Raspberry Pi| Chân Vật Lý (Pin No)|
+-------------------+---------------+------------------+---------------------+
| Màn hình OLED     | VCC           | 3.3V Power       | Pin 1               |
| SSD1306 (I2C)     | GND           | Ground           | Pin 9 (hoặc Pin 6)  |
|                   | SDA           | GPIO 2 (SDA)     | Pin 3               |
|                   | SCL           | GPIO 3 (SCL)     | Pin 5               |
+-------------------+---------------+------------------+---------------------+
| Còi Buzzer 5V     | VCC / (+)     | 5V Power         | Pin 2 (hoặc Pin 4)  |
|                   | GND / (-)     | Ground           | Pin 14              |
|                   | I/O (Signal)  | GPIO 27          | Pin 13              |
+-------------------+---------------+------------------+---------------------+
| Động cơ Rung      | VCC           | 5V / 3.3V        | Pin 2 / Pin 17      |
| (Vibration Motor) | GND           | Ground           | Pin 20 / Pin 25     |
|                   | IN (Signal)   | GPIO 17          | Pin 11              |
+-------------------+---------------+------------------+---------------------+
| Nút Bấm Hiệu Chuẩn| Chân 1        | GPIO 22          | Pin 15              |
| (Recalibrate Btn) | Chân 2        | Ground           | Pin 14 (hoặc Pin 9) |
+-------------------+---------------+------------------+---------------------+
| Mạch Âm Thanh     | Audio In L/R  | Jack 3.5mm Audio | Cổng 3.5mm trên Pi  |
| TDA2050 & Loa     | Nguồn 12V/5V  | Nguồn riêng hoặc | Adapter ngoài       |
+-------------------+---------------+------------------+---------------------+
| Camera USB & Mic  | Cáp USB       | Cổng USB 3.0/2.0 | Cổng USB Raspberry  |
+-------------------+---------------+------------------+---------------------+

4. THIẾT LẬP CƠ BẢN VÀ LỆNH ĐIỀU KHIỂN
--------------------------------------------------------------------------------
1. Kích hoạt môi trường và cài đặt thư viện:
   $ python3 -m venv venv
   $ source venv/bin/activate
   $ pip install -r requirements.txt

2. Kiểm tra nhanh phần cứng:
   $ python3 test_hardware.py
   $ python3 test_oled.py
   $ python3 test_speaker.py

3. Cài đặt Auto Hotspot và Tên miền cố định:
   $ sudo ./setup_autohotspot.sh

4. Chạy hệ thống chính:
   $ chmod +x run_dms.sh
   $ ./run_dms.sh

5. Truy cập Web Dashboard quản trị:
   Mở trình duyệt trên điện thoại hoặc máy tính truy cập: http://wifi.local
   (Khi kết nối vào Wi-Fi phát từ Pi: AI_DMS_Hotspot - Mật khẩu: 1234567890)

6. Xuất báo cáo chuyến đi ra file CSV:
   $ python3 view_history.py --export
