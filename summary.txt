1. TỔNG QUAN HỆ THỐNG
--------------------------------------------------------------------------------
AI_DMS là giải pháp IoT nhúng kết hợp Trí tuệ Nhân tạo (Computer Vision & LSTM)
giám sát an toàn khoang lái, phát hiện buồn ngủ, vi giấc ngủ (>= 3s), ngáp và mất tập trung.
Hệ thống chạy độc lập (Headless), tự phát Wi-Fi Hotspot "AI_DMS_Hotspot" (Pass: 1234567890),
cung cấp Web Dashboard cố định tại http://wifi.local, phát giọng nói cảnh báo Tiếng Việt,
hiển thị OLED I2C 128x64, tự động ghi âm cabin 10s và gửi ảnh cảnh báo qua Telegram Bot.

2. CÁC MODULE CHÍNH
--------------------------------------------------------------------------------
- drowsiness_detector.py : Module xử lý AI, luồng camera, tính toán EAR/MAR, suy luận LSTM.
- lstm_model.py          : Định nghĩa kiến trúc PyTorch LSTM.
- lstm_drowsiness.pth    : Trọng số mô hình LSTM đã huấn luyện.
- audio_manager.py       : Quản lý âm thanh Jack 3.5mm, TDA2050, giọng nói AI, ghi âm Micro USB.
- audio_prompts/         : File âm thanh mẫu (còi bíp, thông báo Tiếng Việt).
- oled_manager.py        : Driver I2C SSD1306 điều khiển màn hình OLED 128x64.
- telegram_bot.py        : Xử lý gửi tin nhắn, ảnh vi phạm và file ghi âm qua Telegram Bot.
- wifi_dashboard.py      : Web Dashboard quản lý hành trình, Wi-Fi, Telegram, Test (Cổng 80).
- mdns_publisher.py      : Dịch vụ công bố tên miền cố định http://wifi.local.
- setup_autohotspot.sh   : Script cấu hình NetworkManager tự phát Hotspot khi mất mạng.
- run_dms.sh             : Script khởi chạy toàn bộ hệ thống bằng 1 lệnh duy nhất.
- view_history.py        : Công cụ CLI truy vấn & xuất lịch sử SQLite ra file CSV.
- test_hardware.py       : Công cụ kiểm tra toàn diện phần cứng.
- test_speaker.py        : Kiểm tra riêng âm thanh & giọng nói Tiếng Việt.
- test_oled.py           : Kiểm tra riêng màn hình OLED 128x64.
- test_camera.py         : Kiểm tra riêng camera USB, độ phân giải & FPS.

4. QUY TRÌNH VẬN HÀNH THỰC TẾ (TỪ QUÉT CCCD ĐẾN KẾT THÚC CHUYẾN ĐI)
--------------------------------------------------------------------------------
1. BẬT NGUỒN & KẾT NỐI WI-FI / WEB:
   - Cấp nguồn cho Raspberry Pi. Hệ thống tự phát Wi-Fi: "AI_DMS_Hotspot" (Pass: 1234567890).
   - Dùng điện thoại kết nối Wi-Fi trên -> Mở trình duyệt vào: http://wifi.local.

2. XÁC THỰC CCCD / VNeID (Chọn 1 trong 3 cách):
   - Cách 1 (Tự động): Giơ thẻ CCCD hoặc mã QR VNeID trước camera (quét tự động trong 2ms).
   - Cách 2 (Nút bấm): Nhấn nút cứng trên xe (GPIO 22) hoặc phím 'V'/'Space' để chụp & OCR.
   - Cách 3 (Qua Web): Mở http://wifi.local -> Tab "Xác Thực VNeID" -> Chọn hồ sơ nhanh,
     chụp ảnh thẻ hoặc nhập CCCD/Tên -> Bấm "Xác Thực".
   - Sau khi xác thực, hệ thống phát loa: "Xác thực căn cước công dân và VNeID thành công!".

3. HIỆU CHUẨN & XỬ LÝ LỖI KHUÔN MẶT:
   - Loa phát: "Vui lòng nhìn thẳng vào camera để xác thực khuôn mặt".
   - Tài xế nhìn thẳng vào camera trong 3-5 giây để hệ thống học Baseline (EAR/MAR/Pose).
   - Khi hoàn tất, loa phát: "Xác thực khuôn mặt thành công. Chúc bạn lái xe an toàn."
   - XỬ LÝ LỖI: Nếu bị lệch góc, ngồi sai tư thế, hoặc đổi người lái -> Nhấn nút bấm GPIO 22
     (hoặc phím 'r', hoặc bấm "Quét lại khuôn mặt" trên Web). Hệ thống sẽ giữ nguyên CCCD
     và Session hiện tại, tự động quét lại tư thế khuôn mặt trong 3 giây.

4. CÁC MỨC CẢNH BÁO KHI LÁI XE:
   - Cấp 0 (Bình thường): Hệ thống im lặng, OLED hiển thị EAR/MAR/FPS.
   - Cấp 1 (Buồn ngủ nhẹ / Ngáp): Loa phát giọng nói Tiếng Việt nhắc nhở nhẹ nhàng.
   - Cấp 2 & 3 (Ngủ gật >= 3s / Mất tập trung lâu): Còi Buzzer kêu liên tục + Động cơ rung ghế/
     vô lăng + Phát giọng nói cảnh báo khẩn cấp + Tự động ghi âm 10s cabin + Chụp ảnh và gửi
     ngay qua Telegram Bot.

5. KIỂM TRA GHI ÂM KHOANG LÁI & XUẤT BÁO CÁO:
   - Nghe file ghi âm: Mở http://wifi.local -> Tab "Ghi Âm Khoang Lái" -> Bấm Play (▶️) nghe
     trực tiếp trên trình duyệt điện thoại/laptop.
   - Xem báo cáo hành trình: Mở http://wifi.local -> Tab "Báo Cáo Chuyến Đi" -> Xem danh sách
     thời gian lái, số lần vi phạm, điểm mệt mỏi Fatigue Score.
   - Xuất báo cáo: Bấm nút "Xuất File CSV" trên Web hoặc chạy lệnh: python3 view_history.py --export.
